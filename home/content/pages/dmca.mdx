Supaboard 作为一个中立的网络传输平台，尊重知识产权并反对任何形式的非法滥用。本页面详细说明了我们如何处理滥用投诉及 DMCA 请求。

## 1. 禁止行为

用户在使用 Supaboard 服务时，严禁从事以下活动：

- **版权侵犯**：通过 P2P/BitTorrent 下载或传播受版权保护的内容（在禁止 BT 的节点上）。
- **网络攻击**：发起 DDoS、端口扫描、暴力破解等攻击行为。
- **非法信息**：传播儿童色情、恐怖主义、极端暴力或其他法律禁止的内容。
- **邮件滥用**：发送垃圾邮件（Spam）。

## 2. 滥用处理机制

当我们收到来自上游机房或版权组织的有效投诉时，我们将采取以下措施：

- **初次投诉**：我们将通过邮件提醒用户，并可能临时限制相关端口或节点的访问。
- **重复违规**：如果同一账户多次收到有效投诉，我们将保留永久封禁账户且不予退款的权利。
- **严重违规**：涉及非法攻击或严重刑事内容的，我们将立即终止服务并清理数据。

## 3. 如何提交滥用投诉

如果您发现有来自 Supaboard 节点的恶意活动，请通过以下方式联系我们的运维安全团队：

- **电子邮箱**：[supaboard@postions.app](mailto:supaboard@postions.app)
- **邮件主题**：Abuse Report - [Source IP Address]
- **必要信息**：请提供完整的日志（Log）、时间戳（Timestamp）以及受害 IP。

## 4. DMCA 通知

作为位于多个司法管辖区的服务提供商，我们遵循相关法律。如果您是版权所有者，请发送包含以下信息的正式通知：

1. 您的电子或物理签名。
2. 您认为被侵权的受版权保护作品的说明。
3. 侵权内容在我们的网络中出现的位置（通常是源站 IP 或 URL）。
4. 您的联系方式（地址、电话、邮箱）。

## 5. 运维承诺

我们将尽力屏蔽已知的恶意流量段，并优化路由以保护用户隐私，同时确保平台的合法运营。
