本教程将指导您在 Windows 系统上使用 **Clash Verge Rev** 客户端配置 Supaboard 订阅。

## 前置准备

- 一台 Windows 10 或 Windows 11 的电脑
- 已注册 Supaboard 账号并获取订阅链接（登录 [用户中心](https://www.supaboard.cc) → 仪表盘 → 一键订阅）

## 第一步：下载 Clash Verge Rev

1. 前往 [Supaboard 下载中心](/download) 下载 **Clash Verge Rev** 的 Windows 安装包。
2. 双击安装包，按提示完成安装。
3. 安装完成后，桌面或开始菜单会出现 Clash Verge Rev 图标。

## 第二步：导入订阅链接

1. 打开 Clash Verge Rev。
2. 点击左侧菜单的 **「订阅」** 栏目。
3. 在顶部输入框粘贴您的 **Supaboard 订阅链接**。
4. 点击 **「导入」** 按钮。
5. 等待节点列表刷新完成。

## 第三步：选择节点并连接

1. 点击左侧菜单的 **「代理」** 栏目。
2. 在节点列表中，选择一个延迟较低的节点（通常选择 **香港** 或 **日本** 节点延迟最低）。
3. 回到主界面，点击 **「系统代理」** 开关开启代理。

> **提示**：如果需要代理游戏、Telegram 等非浏览器应用，请开启 **「TUN 模式」**，效果等同于全局代理。

## 常见问题

### 1. 导入订阅后没有节点
- 请确认订阅链接是否正确复制（以 `https://` 开头）。
- 检查套餐是否已过期或流量耗尽。

### 2. 连接后无法上网
- 确认系统时间与北京时间同步（误差不超过 30 秒）。
- 尝试切换到其他节点。
- 尝试切换代理模式为 **「全局 (Global)」**。

### 3. 部分网站无法访问
- 默认的 **「规则模式 (Rule)」** 只代理国外流量。如果某些网站无法访问，请临时切换为全局模式。
