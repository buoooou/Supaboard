## 第二步：注册 ChatGPT 账号

1. 打开 [https://chat.openai.com](https://chat.openai.com)。
2. 点击 **Sign Up**。
3. 使用 **Gmail 或 Outlook 邮箱** 注册（国内邮箱可能被拒）。
4. 完成邮箱验证。
5. 填写基本信息，完成账号创建。

### 支付方式

**方式一：外币信用卡**
- VISA / MasterCard 均可
- 确保信用卡支持美元支付
- 账单地址填写美国地址（可用 Google Maps 随机查找一个）

**方式二：虚拟信用卡**
- WildCard、Depay 等平台可以开通虚拟 VISA 卡
- 支持支付宝充值
- 注意选择免 KYC 或低 KYC 门槛的平台

> **重要提示**：充值时，确保代理节点的 IP 归属地与信用卡账单地址在同一个国家/地区，否则可能触发 Stripe 的欺诈风控。

## 保持账号安全的建议

1. **固定使用一个地区的节点**：频繁更换 IP 地区会触发 OpenAI 的异常检测。
2. **不要共享账号**：多人同时使用容易被封。
3. **开启双重验证 (2FA)**：保护账号安全。
4. **保持订阅连续性**：中途取消再重新订阅，可能需要重新验证支付方式。
