本教程将指导您在安卓手机上使用 **Clash Meta for Android (CMFA)** 客户端配置 Supaboard 订阅。

## 前置准备

- 一台 Android 7.0 及以上的安卓手机
- 已注册 Supaboard 账号并获取订阅链接

## 第一步：下载 Clash Meta for Android

1. 前往 [Supaboard 下载中心](/download) 下载 **Clash Meta for Android** 的 APK 安装包。
2. 下载完成后，点击安装。如果提示「不允许安装未知来源应用」，请在系统设置中允许。

> **提示**：部分品牌手机（华为、小米等）可能需要手动在「设置 → 安全 → 未知来源」中开启权限。

## 第二步：导入订阅链接

1. 打开 Clash Meta for Android。
2. 点击 **「配置」**（Profile）。
3. 点击右上角 **「+」** 号 → 选择 **「URL」**。
4. 在 URL 栏粘贴您的 **Supaboard Clash Meta 订阅链接**。
5. 为配置取一个名称（如 "Supaboard"）。
6. 点击右上角 **「保存」**。
7. 点击刚添加的配置使其激活（右侧出现选中标识）。

## 第三步：选择节点并连接

1. 回到主界面，点击 **「已停止」** 或 **「点击启动」** 按钮开启代理。
2. 首次使用会弹出 VPN 权限请求，点击 **「确定」**。
3. 进入 **「代理」** 页面，选择延迟低的节点。

## 推荐设置

### 代理模式
- **规则 (Rule)**：推荐日常使用，自动分流国内外流量
- **全局 (Global)**：所有流量都走代理
- **直连 (Direct)**：关闭代理

### 自动更新订阅
进入 **设置 → 配置更新间隔**，设置为 **60 分钟**，确保节点列表自动保持最新。

## 常见问题

### 1. 连接后部分 App 不走代理
进入 **设置 → 网络 → 每应用代理**，确认目标 App 没有被排除。

### 2. 测速显示超时
- 超时不代表节点不可用，可能是测速服务器问题。
- 尝试直接使用该节点访问网页测试实际连通性。

### 3. 华为手机连不上
华为 EMUI 可能会限制 VPN 后台运行。请进入 **设置 → 电池 → 启动管理**，将 Clash Meta 设为「手动管理」并允许后台运行。

### 4. 如何更新节点列表？
进入 **「配置」** 页面，长按当前配置 → 点击 **「更新」**。
